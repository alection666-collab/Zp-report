# Отчёт для зарплаты

Приложение для заполнения отчёта раз в 2 недели: период, работа по площадкам (М / П / Д / Деж), командировки, расходы, долг и итог «Мне должны». Работает без интернета после первой загрузки, данные хранятся на устройстве.

## Выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки (`index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, папку `icons`).
2. Откройте Settings → Pages. В пункте Source выберите «Deploy from a branch», ветку `main` и папку `/ (root)`, нажмите Save.
3. Через минуту-две приложение появится по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Установить на телефон как приложение

1. Один раз откройте адрес в Chrome на телефоне, интернет нужен только для этого.
2. Меню (три точки) → «Установить приложение» или «Добавить на главный экран».
3. На экране появится ярлык с иконкой. Он открывается в отдельном окне, без адресной строки и без интернета.

На iPhone: Safari → «Поделиться» → «На экран Домой».

## Обновление

Измените `index.html` и поднимите версию в `sw.js` (`zp-report-v3` → `zp-report-v4`), чтобы телефон подтянул новую версию.
