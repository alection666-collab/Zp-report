# Отчёт для зарплаты

Заполнение отчёта раз в 2 недели: период, работа по площадкам (М / П / Д / Деж) с автосуммой, расходы, командировки, долг и итог «Мне должны». Работает без интернета, данные хранятся на устройстве.

## Файлы (все лежат в корне репозитория, без папок)

index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png

## GitHub Pages

1. Загрузите все файлы в репозиторий: Add file → Upload files → Commit changes.
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Адрес: https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

## Установка на телефон

Откройте адрес в Chrome → меню (три точки) → «Установить приложение». Если предлагается только «Добавить на главный экран», подождите 10 секунд после загрузки страницы и откройте меню снова.

## Обновление

Замените файлы в репозитории. В sw.js поднимите версию кэша (zp-report-v5 → zp-report-v6).
